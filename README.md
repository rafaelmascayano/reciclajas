# Reciclajas — copia publicada

Esta carpeta contiene una copia estática de los archivos públicos servidos por
https://reciclajas.lovable.app/ el 19 de noviembre de 2026. No es el código
fuente editable de Lovable. Se quitaron los scripts de hidratación y analítica
propios de Lovable; `site/app.js` implementa el menú, el visor de prototipos y
el formulario de contacto.

Para publicar en Netlify desde este repositorio, use `site` como directorio de
publicación. No necesita comando de build.

El formulario de contacto abre la aplicación de correo del visitante mediante
`mailto:`. La copia no incluye un backend de formularios.
